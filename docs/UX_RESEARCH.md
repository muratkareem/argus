# Analyst workspace design research

Public material reviewed 26 October 2026. ARGUS uses original code, visual
assets and layouts; no Palantir screenshots or proprietary assets are bundled.

- [Foundry Workshop tutorial](https://www.palantir.com/docs/foundry/workshop/getting-started): linked object table, filter list, contextual object panel and explicit writeback actions. ARGUS adapts this workflow into transaction filters, contextual evidence and persistent analyst decisions.
- [Object Views](https://www.palantir.com/docs/foundry/object-views/overview): reusable entity representations in full and compact panels. ARGUS keeps a stable transaction/entity inspector across investigation contexts.
- [Full Object Views](https://www.palantir.com/docs/foundry/object-views/use-full-views-in-platform): contextual inspection and resizable views inform the investigation workbench.
- [Gotham public product page](https://www.palantir.com/platforms/gotham/): relationship-oriented investigation is treated as inspiration; ARGUS's graph remains an explicitly synthetic SQL fixture, not an invented ULB ontology.
- [AIP overview](https://www.palantir.com/docs/foundry/aip/overview): structured operational context and separation of interpretation from evidence inform the restricted local Copilot.

The design system uses flat navy surfaces, thin separators, compact typography,
restrained blue-gray/teal accents and reserved risk colors. Resizing, saved
filters, search, graph traversal and linked evidence must perform real actions.
ARGUS does not imply Palantir-level governance, permissions, enterprise scale or
regulatory certification.

The public Workshop screenshot and Gotham product demonstration were also
inspected in a browser. Only general panel hierarchy, compact metadata and
context-preserving navigation informed ARGUS. Gotham demonstration domain assets
and marketing animations are not included. The public Gotham security overview
was reviewed separately; ARGUS does not claim its enterprise security capabilities.
