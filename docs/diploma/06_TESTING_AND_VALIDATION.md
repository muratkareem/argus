# Testing and validation

Backend tests cover exact schemas/nonfinite input, missing model, provenance isolation, single/batch consistency, request thresholds, risk outputs, SHAP for every candidate, additivity/cache, artifact integrity, repeated training, concurrent activation, duplicate labels, transactional rollback/concurrent imports, migration preservation, SQLite foreign keys, query plans, bounded graph neighborhoods, saved views, investigation persistence and optional authentication/CORS.

Final verification on 14 November 2026: `.venv/bin/pytest -q` **78 passed** in 5.36 s (SQLite); the same suite with `ARGUS_TEST_DATABASE_URL=postgresql+psycopg://main@127.0.0.1:55432/postgres` **78 passed** in 7.41 s on an isolated PostgreSQL 17 cluster. Ruff lint/format and compileall pass. One Starlette/httpx deprecation warning remains; coverage percentage was not measured.

Frontend lint/typecheck, 12 unit tests across five files and final production build pass. The final clean Chrome Playwright run passed **12/12** in 13.9 s. Native bootstrap was invoked twice and reused the active model and 600 existing demo records. Final Docker Compose built both images, started all three services healthy, and passed frontend proxy, PostgreSQL health, model readiness, scored-count and observed-label smoke assertions. Ports 18000/18080 and project argus-diploma isolated verification from user workspaces; containers and the separate native PostgreSQL test cluster were stopped afterward, preserving data. Smoke evidence: ../research/diploma-compose-smoke.json.

Commands from root: `.venv/bin/ruff check backend scripts`, `.venv/bin/ruff format --check backend scripts`, `.venv/bin/python -m compileall -q backend scripts`, `.venv/bin/pytest -q`. Optional PostgreSQL suite uses `ARGUS_TEST_DATABASE_URL` and creates isolated test schemas. From frontend: `npm run lint && npm test && npm run build`, then `ARGUS_BROWSER_CHANNEL=chrome npm run test:e2e` against an isolated bootstrapped development DB/model. Browser tests write synthetic records and screenshots; never aim them at a valuable workspace.

Delivery re-audit after compatible updates reports seven moderate development-only advisories, zero high/critical; production-only audit reports zero. See ../SECURITY_REVIEW.md. Audit results are point-in-time and do not establish vulnerability freedom. Docker and browser verification completed; exact outcomes also appear in PROGRESS.md.
